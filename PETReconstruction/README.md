# PET 图像重建系统（CPU + CUDA GPU 加速）

## 项目概述

基于 MFC 框架开发的 PET（正电子发射断层扫描）图像重建系统，实现了 MLEM / OSEM / FBP 三种重建算法，支持 CPU 串行与 CUDA GPU 并行两种执行路径。系统通过 MFC 界面逐帧刷新显示重建中间结果，可直观观察迭代收敛过程，并对比 CPU/GPU 性能差异。

## 技术栈

| 层面 | 技术 |
|------|------|
| 界面框架 | MFC (CDialog/CDC 双缓冲绘图) |
| 核心语言 | C++17 |
| GPU 加速 | CUDA 12.4 + cuFFT |
| 数学运算 | 双线性/三线性插值、FFT、泊松统计建模 |
| 数据格式 | PGM 图像、自定义正弦图格式 |

## 核心算法

### 1. MLEM（最大似然期望最大化）

基于泊松统计模型推导的迭代重建算法，每次迭代使用全部投影角度：

$$\lambda_j^{(k+1)} = \lambda_j^{(k)} \cdot \frac{\sum_i H_{ij} \cdot \frac{y_i}{\sum_{j'} H_{ij'} \lambda_{j'}^{(k)}}}{\sum_i H_{ij}}$$

- $y_i$：测量正弦图（第 $i$ 条 LOR 的计数）
- $H_{ij}$：系统矩阵（像素 $j$ 对 LOR $i$ 的贡献）
- $\lambda_j$：重建图像（像素 $j$ 的活度值）

### 2. OSEM（有序子集期望最大化）

将投影角度分成 $K$ 个子集，每个子集执行一次 MLEM 更新，收敛速度约为 MLEM 的 $K$ 倍：

$$\lambda_j^{(k,s+1)} = \lambda_j^{(k,s)} \cdot \frac{\sum_{i \in S_s} H_{ij} \cdot \frac{y_i}{\bar{y}_i}}{\sum_{i \in S_s} H_{ij}}$$

采用**交错采样**划分子集（子集 $s$ = 角度 $\{s, s+K, s+2K, \ldots\}$），保证每个子集覆盖完整角度范围，收敛更稳定。

### 3. FBP（滤波反投影）

对正弦图每行做 1D FFT → 乘 Ramp 滤波器 → IFFT → 反投影，作为解析重建基线。

## CUDA GPU 加速

### 并行策略

| Kernel | 功能 | 并行映射 |
|--------|------|----------|
| `kernelPETForwardProjectSubset` | 子集正投影 | 1 线程 = 1 (角度, 径向bin) |
| `kernelPETBackProject` | 反投影 | 1 线程 = 1 像素 |
| `kernelElementDiv` | 逐元素除法 $y_i/\bar{y}_i$ | 1 线程 = 1 元素 |
| `kernelMLEMUpdate` | 乘法更新 $\lambda_j$ | 1 线程 = 1 像素 |
| `kernelElementClamp` | 数值钳位（防除零） | 1 线程 = 1 元素 |

### GPU 内存优化

- **子集紧凑存储**：正投影缓冲区只分配子集大小（`nSubAng × numBins`），而非全角度，内存减少 $K$ 倍
- **预分配复用**：`d_subOnes`（全1正弦图）在迭代前分配一次，所有子集复用
- **角度索引数组**：`d_angleIndices` 传递子集角度索引，避免 kernel 内分支判断

### OSEM 单子集 5 步流程

```
① 灵敏度图   S_j = Σ_{i∈sub} H_ij          ← 反投影子集全1正弦图
② 正投影     ȳ_i = Σ_j H_ij · λ_j           ← 仅子集角度
③ 比值       r_i = y_i / ȳ_i                 ← 逐元素除法
④ 反投影     corr_j = Σ_{i∈sub} H_ij · r_i  ← 仅子集角度
⑤ 更新       λ_j *= corr_j / S_j             ← 乘法更新 + 非负约束
```

### CUDA Event 精确计时

使用 `cudaEventRecord` / `cudaEventElapsedTime` 测量纯 GPU 计算时间，排除 host↔device 数据传输开销。

## MFC 逐帧刷新显示

### 显示机制

- **双缓冲绘图**：在内存 DC 中绘制重建图像，通过 `BitBlt`/`StretchBlt` 一次性贴到屏幕，消除闪烁
- **逐迭代刷新**：每次迭代完成后调用 `Invalidate()` → `UpdateWindow()` 触发 `OnPaint` 重绘，实时显示收敛过程
- **伪彩映射**：将浮点重建结果映射为灰度/Hot 伪彩，支持窗宽窗位调节

### 交互功能

- 选择重建算法（MLEM / OSEM / FBP）
- 选择执行路径（CPU / GPU）
- 调节迭代次数、子集数
- 实时显示当前迭代次数、对数似然值、耗时
- CPU/GPU 结果并排对比 + 差值图

## 校正模块

| 校正类型 | 方法 | 参数 |
|----------|------|------|
| 衰减校正 | 正投影时乘以 $e^{-\int \mu \, dl}$ | $\mu = 0.096$ cm⁻¹ (水 @511keV) |
| 散射校正 | 加性项 $s_i$ 加入估计值 $\bar{y}_i$ | scatterFraction = 0.1 |
| 随机校正 | 均匀随机符合估计 | randomsRate = 0.05 |
| PSF 建模 | 高斯卷积分辨率建模 | FWHM = 4.0 mm |

## 体模与数据

| 体模 | 用途 |
|------|------|
| Derenzo 体模 | 分辨率测试（6 组不同尺寸热点） |
| NEMA IEC 热球体模 | 定量恢复测试（6 球 + 背景） |
| 均匀圆柱体模 | 归一化校正 |
| 自定义热点体模 | 灵活测试 |

支持 2D 和 3D（逐切片）两种模式，3D 模式下每个切片独立重建。

## 关键技术亮点

1. **OSEM 子集正投影优化**：正投影只计算子集角度，计算量减少 $K$ 倍
2. **GPU 内存预分配策略**：避免迭代内反复 `cudaMalloc/cudaFree`
3. **数值稳定性保障**：钳位 $\bar{y}_i \geq 10^{-10}$ + 灵敏度下界保护 + 非负约束
4. **MFC 逐帧可视化**：双缓冲 + 逐迭代刷新，直观展示迭代收敛过程
5. **完整校正链**：衰减 + 散射 + 随机 + PSF 四种校正
